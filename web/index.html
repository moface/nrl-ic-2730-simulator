手咪说明与功能键设置

六位频率自动确认，例如 435680。先按 * 再输入 540，可修改当前 MHz 下的小数部分。# CE 删除，CLR 取消。

▲▼可长按连续调节；VFO/MR 长按锁定；HOME 长按切换呼叫模式。呼叫 C0/C1 与 HOME 使用仿真预设频率。

DTMF 与 1750 Hz 只在浏览器中模拟提示音；没有话筒采集、NRL 连接或射频发射。菜单内上下键选择或修改，CLR 退出；ENT 只用于手咪输入确认。

操作指南

像操作熟悉的机头一样。

旋钮点旋钮左半边减一格，点右半边加一格，按住不动会连续调节。选中后也可用键盘方向键微调。

频率双击液晶频率输入数值。左右 MAIN 分别选择操作段。

电源长按 1 秒开关机，短按静音。

功能键短按选择常用功能，长按调用第二功能。MENU 长按锁定。

菜单旋钮选择项目，MONI（◀）返回上一级，LOW（▶）进入设置，MW（↵）进入或确认，MENU（CLR）退出。

PTT按住屏幕按钮或空格键模拟发射，松开即停止。

这是离线交互原型，不连接 NRL、不使用麦克风、不发射射频。菜单与扫描为体验用简化模拟，后续依真实采集结果校准。
